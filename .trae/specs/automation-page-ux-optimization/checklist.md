# 自动化页面 UX/UI 优化 - 验证清单

## 结构与布局
- [ ] 页面顶部显示「自动化」标题和描述文字，右侧有「手动新建」「在对话中创建」两个按钮
- [ ] 三个 Tab（已配置/执行历史/任务模板）正确渲染，默认选中「已配置」，Tab 切换正常
- [ ] Tab 切换不重置已加载数据（切换回来时保持滚动位置）
- [ ] 页面最大宽度 max-w-6xl 居中，与项目其他面板一致

## 已配置 Tab
- [ ] 任务列表以行卡片形式展示，每行包含：图标、名称、模式标签、自然语言调度、更多菜单、立即运行、Switch
- [ ] 调度时间显示为自然语言（"每天 07:00"），不显示 cron 表达式
- [ ] Switch 开关切换时调用 updateSubscription，有 loading 状态，成功刷新列表
- [ ] 立即运行按钮点击时调用 runSubscription，有 toast 反馈
- [ ] 更多菜单（DropdownMenu）包含编辑/删除选项，删除弹出确认对话框
- [ ] 空状态显示引导文案和推荐快捷按钮
- [ ] 蓝色本地运行提示条显示在列表顶部，信息图标+文字+保持唤醒 Switch
- [ ] 任务卡片 hover 效果自然（背景色微变），无阴影/无缩放动画

## 执行历史 Tab
- [ ] 顶部筛选栏：状态下拉（全部/成功/失败/运行中）、类型下拉、日期范围选择器
- [ ] 历史记录按日期分组（今天/昨天/具体日期）
- [ ] 每条记录显示：状态图标（绿对勾/红叉/灰钟）、任务名、模式标签、触发方式、耗时
- [ ] 状态图标颜色：成功=primary，失败=destructive，运行中=muted-foreground
- [ ] 点击历史记录展开/跳转到详情，详情使用扁平标题（无深色渐变 ReportCover）
- [ ] 筛选功能正确（前端过滤 reports 数组）
- [ ] 空状态显示引导文案
- [ ] 加载时显示骨架屏，非大转圈

## 任务模板 Tab
- [ ] 3 列网格布局展示 8 个预设模板卡片
- [ ] 每个卡片包含：窗口风格图标、标题、描述
- [ ] 卡片 hover 效果：border 颜色变 primary/30，背景变 card
- [ ] 第一个/推荐卡片有高亮样式
- [ ] 点击卡片打开「手动新建」对话框并预填模板参数

## 手动新建对话框
- [ ] 对话框可通过「手动新建」按钮打开，点击遮罩/取消按钮关闭
- [ ] 表单字段：任务名称（必填）、目标描述（必填）、频率（必选）、时间、周几/几号
- [ ] 频率为"高频"时时间字段禁用；为"每周"时显示周几选择；为"每月"时显示日期选择
- [ ] AI 生成按钮（SparklesIcon）可根据目标描述自动填充调度参数
- [ ] 表单验证：名称和目标描述为空时显示错误提示，提交按钮禁用
- [ ] 提交成功后关闭对话框、显示 toast、刷新任务列表
- [ ] 从模板打开时字段预填正确

## 在对话中创建
- [ ] 点击「在对话中创建」按钮跳转到聊天页面（/workspace/agents?surface=chat）
- [ ] （可选）聊天输入框自动预填引导消息

## 视觉与风格合规
- [ ] 所有新增/修改文件无硬编码 Tailwind 颜色类（text-emerald-*, text-amber-*, bg-red-*, text-purple-* 等）
- [ ] 统一使用语义令牌：--foreground, --muted-foreground, --primary, --destructive, --border, --card, --background, --muted
- [ ] 圆角统一：卡片 7px，按钮 5px，Dialog 7px
- [ ] 无 backdrop-filter blur、无 scale 动画、无深色渐变背景、无网格纹理装饰
- [ ] ReportCover 组件已移除深色渐变，改为扁平风格或直接删除
- [ ] 蓝色提示条使用 bg-primary/5 border-primary/15 等语义色，不突兀

## 加载与错误状态
- [ ] 所有数据加载时显示骨架屏（Skeleton），不使用居中 Loader2 大转圈
- [ ] 加载错误显示错误提示条+重试按钮，不使用红底刺眼样式（用 bg-destructive/5 border-destructive/20 text-destructive）
- [ ] mutation 操作（创建/更新/删除/运行）中按钮显示 loading 状态，防止重复提交

## i18n

- [ ] zh-CN.ts 中包含所有必要的中文翻译键
- [ ] TypeScript 类型检查通过，无缺失键报错

- [ ] 所有现有测试通过（pnpm test）
