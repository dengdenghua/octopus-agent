**目标(用户拍板)**:octopus-mobile 要「类似豆包的实时语音对话」(不是语音转文字),方案=**混合**:omni-realtime 实时对话 + agent 工具接管(Phase 3)。计费用户已定=按分钟(免费额度→积分)。

**关键上游认知(实测踩坑)**:实时 WS **必须走标准 host** `wss://dashscope.aliyuncs.com/api-ws/v1/realtime`,**不是** .env 里的 workspace 专属域 `ws-....maas.aliyuncs.com/compatible-mode/v1`(后者只做 HTTP 聊天,实时路径 404;直连专属域的 `/api-ws/v1/realtime` 回 InternalError)。认证 `Authorization: Bearer <QWEN_API_KEY>` + **`OpenAI-Beta: realtime=v1`**(漏这个头连不上);key 是账号级的,标准 host 也认。协议=OpenAI-Realtime 兼容事件(session.update / conversation.item.create / response.create → response.audio.delta base64 分片 + response.audio_transcript.delta)。默认输出 pcm16;voice 用 "Cherry"。

**Phase 1 服务端代理(已完成+生产验证)** 提交 **abe43e2**:
- 端点 `@app.websocket("/voice/realtime")`:客户端 ↔ 本服务 ↔ DashScope。为什么必须中转:①key 只在服务端 App 永不见 ②按分钟计费/门控只能服务端强制。流程=鉴权(user_from_bearer_token)→ 预扣首分钟(付不起且无免费额度则**零成本拒绝、不连上游**)→ 连上游注入默认会话参数(中文口语/pcm16/服务端VAD)→ 双向透传 + 每 60s 计费一分钟(voice.tick 事件兼保活)。
- `_VoiceMeter` 计费状态机:免费分钟(会员 voice_free_min_member/游客 voice_free_min_guest 每日额度)优先 → 耗尽按 voice_credits_per_min 扣 3 桶积分(复用 _reserve_usage_credits)→ 单次封顶 voice_max_session_min。整分钟向上取整。参数全走 config_kv(运维面板可调,已在 PRICING_KEYS 白名单)。
- 新表 `voice_sessions`(通话台账,今日已用免费分钟=SUM(free_minutes) WHERE started_ms≥当天UTC0点)。`GET /voice/quota`(通话前查剩余免费分钟+单价+可撑分钟)。requirements 加 websockets>=12。
- 测试 +11(计费状态机/额度/WS中继/鉴权失败/额度不足零成本拒绝/未配置),全套 **216 通过**。

**语音↔文字记忆打通 L2(vc14)**:用户问"为啥语音和文字对话记录不共享"——根因:语音走 DashScope omni + 从没写 ChatStore,文字/TV桌面走 ChatAgentBridge + ChatStore/SessionStore(**同角色跨对话页/TV桌面共享**),两套断开(不同大脑 + 语音无持久化)。用户选 **L2 双向连续**。命门先探:`input_audio_transcription` 用 **`gummy-realtime-v1`** 能转录用户语音(默认{}不转)→ 拿到"用户那半句"。实现 commit ad34b5e:服务端注入开 gummy 转录;VoiceRealtimeClient 加 seedHistory(连上后把最近历史作 conversation.item 注入 omni 续上下文)+ onUserTurn(transcription.completed)/onAiTurn(response.audio_transcript.done);VoiceCallActivity.bindSharedSession 按 `CharacterRegistry.current.id` 取同一角色 SessionStore 当前会话、ChatStore.load 最近12条注入、每轮 appendVoiceTurn 存回。**生产 e2e**:抓音频当用户输入送代理→用户转录 relay 回(可存历史)+ AI 正常答 + **AI 回答用上了注入的 seed 历史(问"云南"它接着云南聊)**→ 语音真接着文字上下文。已发布 vc14 全渠道(sha 33d73792)。

**⚠️ 免提外放坑(vc13 修)**:AudioOut 用 `USAGE_VOICE_COMMUNICATION`(为配对硬件 AEC)默认路由到**听筒**(贴耳小喇叭)→ 用户反馈"没开免提声音太小"。修:VoiceCallActivity 进通话页 DisposableEffect 切 `AudioManager.MODE_IN_COMMUNICATION`(保留 AEC)+ 强制扬声器(API31+ `setCommunicationDevice(TYPE_BUILTIN_SPEAKER)`,旧版 `isSpeakerphoneOn=true`),离屏还原 mode。commit a5b8326,versionCode 12→13。模拟器实测系统日志 `AudioDeviceBroker...type:speaker...setCommunicationDevice()` 确认路由到扬声器。**已发布 vc13 全渠道**(下载站 OctopusMobile_v1.0.0.apk + _vc11.apk + OTA octopus-latest.apk 三处 sha=4b422106;官网 download.ts ?v=20260707 + sha 更新 rebuild;OTA APP_UPDATE_VERSION_CODE=13;vc12→vc13 同签名原地升级实测成功)。
