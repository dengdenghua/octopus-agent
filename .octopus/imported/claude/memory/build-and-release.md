Building & releasing **octopus-mobile** (Android, applicationId `com.octopus.mobile`, namespace `com.apk.claw.android`):

- **版本号规则(2026-07-04 用户拍板):** 公开版 versionName 从 **0.0.1** 重新起号,但 **versionCode 只能单调递增**(历史内部包到 7,0.0.1 对应 versionCode 8)——显示名与升级判据解耦,别把 versionCode 跟着显示名回退。首个公开版 = 0.0.1/vc8(2026-07-04,含广场/Shizuku 自动配置/OTA/崩溃上报)。
- **1.0.0 正式版 = vc9(2026-07-05):** 首个 stable。相比 0.0.1 增:对话多轮上下文([[testing-jvm-stores]] ConversationContext)、长期记忆接对话页读写+MEMO 采集(MemoryStore)、多角色会话隔离(SessionStore 加 character 字段,旧数据 null→本体,proguard keep SessionStore$SessionMeta)、MediaProjection 高清采集(20-30fps,capture/ 包,系统授权非静默)、浏览器/玻璃视觉修复。universal sha256 `e85ad03b…193c`(082403 最终版,含白横条+保活修复;旧 sha 作废)。真机(模拟器登录态)已验:升级安装/启动无崩溃/首页搜索框/前台服务保活。**残留未验证:红米8A(v7a 32位+Android9)闪退——用户报过,模拟器不翻译32位ARM 复现不了。**
- **无障碍保活真因(2026-07-05,关键坑,429e319):** 「开无障碍后滑返回就自动关」真凶不是 Activity finish([[shizuku-autosetup]] 无关;KeepAliveBack 只防 finish,不够),是 **ForegroundService.start 首行查 POST_NOTIFICATIONS,没授予就 return false 静默不启动前台服务** → 进程无保活 → 真机(MIUI)退后台被回收 → 同进程无障碍陪葬。Android 13+ 前台服务**无需**通知权限即可启动(该权限只管「运行中」通知是否可见)。已去掉该检查 + 重启条件 hasLlmConfig()→ClawAccessibilityService.isRunning()(平台中转登录用户无 BYO key,hasLlmConfig 恒 false 原来也不重启)。模拟器回收宽松不复现,靠 `adb shell dumpsys activity services com.octopus.mobile` 看 ForegroundService `isForeground=true` 验证(撤销通知权限后仍启动=修复生效)。首页搜索框「白横条」真因=Surface `shadowElevation=8dp` 让半透明白浮起成双层,去掉即消。

- **Build cmd:** `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew :app:assembleDebug` (or `assembleRelease`, ~2–5 min with R8). Debug ~5–20s incremental.
- **adb:** `$HOME/Library/Android/sdk/platform-tools/adb` (not on PATH). build-tools at `$HOME/Library/Android/sdk/build-tools/36.1.0/` (apksigner needs JAVA_HOME/PATH set to run).
- **Signing:** release config reads `KEYSTORE_FILE / KEYSTORE_PASSWORD / KEY_ALIAS(=octopus) / KEY_PASSWORD` from **gitignored `local.properties`**; keystore = `release.keystore` (alias octopus, cert SHA-256 `BE:4D:2E:B2…CE:4F:5E`). Verify: `apksigner verify --print-certs <apk>` (v2 scheme; minSdk 28 so v2 is enough).
- **ABI splits (since 0.0.2):** `splits { abi { isUniversalApk=false; include "arm64-v8a","armeabi-v7a" } }` → TWO APKs, each only its arch. Output filename injects the ABI (via `androidComponents.onVariants` → `variantOutputConfiguration.filters` ABI identifier) to avoid same-name packaging collision. Don't add a universal APK — both archs combined ≈ 370MB. Same versionCode on both = fine for sideload; for Play use AAB.
- **Sizes:** arm64-v8a ≈ **237MB**, armeabi-v7a ≈ **201MB**. Dominated by bundled **GeckoView** `libxul.so` ≈ 144MB (in-app browser + AMO extensions). Only way to shrink hard = drop GeckoView for system WebView (loses extensions). mpv/ffmpeg libs were **removed** (~-40MB) because MpvController is a stub; video playback not wired.
- **R8 gotcha (Coil):** release minify strips **Coil** (image loader for browser favicons / engine icons) → blank images in release, fine in debug. proguard-rules.pro now has `-keep class coil.** { *; }` + `-dontwarn coil.**`. Glide/OkHttp keeps already existed. Always smoke-test the **release** build (favicons, native loads), not just debug.
- **R8 gotcha (Gson wire DTOs):** all Gson DTOs rely on **field name == JSON key** (no `@SerializedName`), so R8 renaming silently breaks parsing (→ null/empty, falls back to seed). Every such DTO needs an explicit `-keep class … { *; }`. Covered: `com.apk.claw.android.account.**`. **Easy to miss:** DTOs that live OUTSIDE `account` — the 广场/技能中心 ones are in `ui.compose.screen` (`SquarePostDto`, `SquareFeedDto`, `DiscoveryPostDto`, `DiscoveryFeedDto`, `RemoteConfig$AppConfigDto`); added their keeps in commit `f0844c5` (v0.0.7). Rule: any new server-driven feature with a Gson DTO must add a keep, or it works in debug and silently degrades in release. Verify via `app/build/outputs/mapping/release/mapping.txt` — kept classes map to themselves (`X -> X:`).
- **Emulator quirk:** this x86_64 emulator runs the arm64 APK via ARM translation (works, incl. GeckoView). Can't test armeabi-v7a (32-bit ARM not translated). Launch is flaky: `am start`/`monkey` often don't foreground; tap the launcher icon (predicted-app slot moves after reinstall — re-find via `uiautomator dump | grep octopus`). Per-app locale for testing: `adb shell cmd locale set-app-locales com.octopus.mobile --locales zh-CN` (reset with `--locales ""`).
- **APK 瘦身(2026-06-30,零功能损失 −23MB):** 体积账单(arm64 release):GeckoView ≈180MB(`libxul.so`144 + 其它 mozilla .so ~22 + `assets/omni.ja`13)= **76%**;dex 52MB;arsc/res ~2MB。**dex 大的真因不是重依赖,而是 `proguard-rules.pro` 里祖传通配 `-keep class androidx.** { *; }`/`-keep interface androidx.** {*;}` 把 R8 对整个 AndroidX/Compose 的收缩全关了** —— release 里保留了 **9905 个 Material 图标 getter 类(app 只用 71 个)**。修法:① 删掉那两条 androidx 通配 keep(AndroidX AAR 自带 consumer 规则覆盖 ViewModel/Compose 反射,无需整包保活);② 删 keep 后 R8 全程序分析会把 markwon-image 的可选 Svg/Gif decoder 对未声明依赖的悬空引用当“缺失类”报错中断构建 → 加 `-dontwarn com.caverock.androidsvg.**` + `-dontwarn pl.droidsonroids.gif.**`;③ `defaultConfig { resourceConfigurations += setOf("en","zh","ja") }` 丢库自带的几十种语言(**必须含 ja**,app 有 values-ja/values-zh,否则误删自带翻译)。结果:**arm64 238→215MB,armeabi-v7a 201→179MB;dex 52→31MB(−40%),图标 9905→68 类,arsc 1.94→0.72MB**。已 emulator release 烟测:登录页 Compose/图标/中文全正常渲染,无崩溃。注意 io.netty/jackson/langchain4j/coroutines/utilcode 也有同类整包 `{*;}` keep,可同法继续收(但 Netty/Jackson 反射多,风险高需逐一验)。
- **GeckoView 已移除(2026-06-30,238→35MB):** 接上一条之后,按用户决定**彻底删掉 GeckoView(Firefox 内核)换系统 WebView**。删:`build.gradle.kts`/`libs.versions.toml` 的 geckoview 依赖 + `GeckoViewEngine.kt`/`ExtensionInstaller.kt`/`CrxToXpiConverter.kt`/`ExtensionsActivity.kt` + `assets/extensions/`(octopus-bridge);`BrowserEngineFactory.selectBest/listAvailable` 只回 `SystemWebViewEngine`(已存在,接口完整,antiBot=50);扩展功能下线(`supportsExtensions=false` 守卫早已写好,`BrowserActivity.showExtensionDialog`/`InstallExtensionTool` 改为不支持;移 FeatureHub/BrowserSettings 的扩展入口 + manifest 的 ExtensionsActivity 声明)。`PcRemoteWebrtcActivity` 本就用系统 WebView,不动。结果:**arm64 238→35MB,armeabi-v7a 201→34MB(−85%)**;native .so 166→0.69MB(只剩 libmmkv,libxul/omni.ja 全消失);残留 `mozilla/public-suffix-list.txt` 是 **OkHttp 的,不是 Gecko**。失去:WebExtension(uBlock 等)+ Firefox 级反爬(90→50);后续靠自建注入式插件生态(registry mode=inject/kind=code)+ document-start stealth 注入 + 服务端匿名抓取补。**替代运行时已落地(2026-06-30,APK 仍 35MB):** ① 加 `androidx.webkit` 依赖;② 新 `BrowserPluginHost.kt`(`octopus_mobile.browser` 包)= 注入式插件运行时:`STEALTH_JS`(document-start 反检测,移植自 puppeteer-stealth:webdriver/chrome/plugins/languages/WebGL/permissions + toString 伪装)+ `setPlugins`/`setBlockRules` 注册表 + `contentScriptsFor(url)`/`shouldBlock(url)`/`documentStartScript()` 读出口 + `loadFromFile(ctx)` 读本地清单;③ `SystemWebViewEngine` 接入:`WebViewCompat.addDocumentStartJavaScript`(探测 `WebViewFeature.DOCUMENT_START_SCRIPT`,不支持退回 onPageStarted 注入 stealth)+ `shouldInterceptRequest` 调 shouldBlock 拦广告 + onPageFinished 注 contentScripts,**antiBotScore 50→70**;④ `BrowserActivity.onCreate` 在 createView 前调 `BrowserPluginHost.loadFromFile(this)`。**插件投递契约(服务端格式未定前的临时落地):`filesDir/registry/browser_plugins.json` = `{stealthEnabled, plugins:[{id,name,hostPattern(正则),js,enabled}], blockRules:[正则]}`** —— registry 消费层/agent/手动都能写它。**未做:registry→BrowserPluginHost 的真实数据接线(等服务端 inject/code 资产契约);服务端匿名抓取兜底(另仓+基建)。stealth/拦截/注入的端到端验证需登录后开浏览器(WebView 受 login 门控,本会话只验到 build 绿 + 启动不崩)。emulator 烟测:启动/登录页正常无崩溃无 ClassNotFound;**在线浏览器需登录后手验(WebView 渲染未端到端跑通,但 SystemWebViewEngine 是标准件、PcRemoteWebrtc 已证可用)**。
- **R8 full mode 必须关(关键 gotcha):** 收窄 `androidx.**` 通配 keep 后,整个 Compose/AndroidX 暴露给 R8 **full-mode 全程序优化**,冷缓存下会**卡死**(实测 jstack 确认 R8 在 `com.android.tools.r8.internal.*` 优化阶段 >35min 不收敛,236%+ CPU 空转,build 超 55min 未完)。解法:`gradle.properties` 加 **`android.enableR8.fullMode=false`**(compat 模式)→ 构建恢复 ~5min,仍做收缩/裁剪(体积收益全保,dex 反而 29.6MB),只跳过昂贵全程序优化。删 geckoview 这类改依赖图的操作会让 R8 全冷,务必带这个 flag。
- strings.xml are **CRLF + BOM** — append before `</resources>`, don't let an editor reflow to LF (diff explodes). **例外:`values-ja/strings.xml` 是普通 LF 无 BOM**,直接文本插入即可。**部分 Kotlin 源码也是 CRLF(实锤:TaskOrchestrator.kt)** —— 用 python/sed 整文件重写做替换会把行尾刷掉(踩过:dc45524 刷了 1272 行噪音,d03bd3b 修复)。改这类文件用 Edit 工具做精准替换,或 python `open(newline='')` 保留原样。See [[web-control-console]] for security-fix details.
- **Kotlin 注释嵌套坑(2026-07-04 真实炸过):** Kotlin 块注释**可嵌套**(和 Java 不同),KDoc 里写字面 URL 通配 `/square/*` 这种含「斜杠星号」的文字会新开一层注释永不闭合 → 编译器在 EOF 报 `Unclosed comment`,整个文件被吞、下游全是 Unresolved reference(错误列表可能被截断,根因藏在中间一行 Syntax error)。注释里写路径通配要改写(如「/square/ 开头的前缀」)。
- **OTA 在线更新(0.0.7 起):** 发版多一步 —— 把 **universal** 签名包传到服务器 `APP_UPDATE_APK_PATH`(默认 `server/downloads/octopus-app.apk`),配 env `APP_UPDATE_VERSION_CODE/_VERSION_NAME/_NOTES/_FORCE`;客户端 `AppUpdater` 启动静默查 + 设置页手动查 `GET /app/latest`。未配置时服务端回 versionCode=0,客户端视为"已最新",不报错。签名密钥不经手服务端。
- **GitHub Actions 长期瘫痪(2026-07-04 发现):** 账号计费失败("recent account payments have failed"),所有 CI 秒挂 —— 本地必须自己跑四件套兜底,直到用户去 GitHub Billing 修复。
- **lint 的 MissingTranslation 连锁:** 补了 ja 后 lint 转而要求同批 key 在 **values-zh** 也齐(key 一旦开始翻译就要求全 locale 覆盖);zh 直接从默认 values/(本就中文)原样复制。默认 values/ 是 CRLF+BOM、values-ja/values-zh 是 LF 无 BOM。
- **lint 门禁的 MissingTranslation 是 error 级棘轮:** 新增 UI 字符串必须同步补 `values-ja`(zh 是默认 locale 不缺),否则 `:app:lintDebug` 挂门禁。发版前本地跑 CI 四件套:`assembleDebug lintDebug detekt testDebugUnitTest`(注意 `| tail` 会吃掉退出码,用 `; echo EXIT=$?` 显式回显)。
