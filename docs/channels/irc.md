# IRC 接入指南

## 概述

IRC 通道让 Octopus-Agent 作为一个真实成员加入 IRC/IRCv3 房间。收到的消息会进入统一渠道路由，可绑定单个 Agent 或持久 AI 团队。

## 配置

在「渠道」页面选择 IRC，填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| IRC Server | 服务器域名 | `irc.libera.chat` |
| Port | 服务器端口 | `6697` |
| Nickname | 机器人昵称 | `octopus-agent` |
| Channels | 逗号分隔的房间 | `#octopus, #agents` |
| Server Password | 可选服务器密码 | 留空 |
| TLS | 默认启用 | `true` |

保存后服务会立即建立长连接。服务重启会自动恢复连接；网络中断后按退避策略重连。更新配置时会先启动新连接，成功后才关闭旧连接，避免一次错误配置让原通道离线。

## 行为与限制

- 支持 IRCv3 `message-tags` 和 `server-time`；服务端提供消息 ID 时会参与跨进程幂等去重。
- 群聊线程按房间隔离，私聊线程按发送者隔离。
- 自动响应 `PING`，模型执行不会阻塞连接保活。
- 长消息按 IRC 512 字节限制做 UTF-8 安全分片。
- 目前支持纯文本；附件、编辑、输入状态和表情回应不在 IRC 标准能力内。

在渠道卡片上点击「健康检查」可以确认当前长连接是否存活。
