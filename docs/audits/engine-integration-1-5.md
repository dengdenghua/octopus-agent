## 实施结果

| 项目 | 本次落地 | 边界 |
| --- | --- | --- |
| 1. 账号与模型兼容 | 回归 Codex 登录续期、主体隔离、模型目录校验、共享模型代理；回归 OpenCode Zen/Go 共用 Key、Key 轮换、匿名免费模型价格校验 | 不迁移或混用两个引擎的凭据；没有凭据的第三方云模型未做真实端到端调用 |

| 3. 公共事件与搜索格式 | OpenCode 原生搜索、抓取事件映射到 web_search / web_fetch，保留原始工具名和执行引擎；宿主搜索统一标题、URL、摘要、来源、提供方、耗时和结果数量，并去重 | 沿用现有 HostToolBroker；原生搜索正文未强行解析成宿主搜索结果，其他原生工具事件保留现有协议 |
| 4. 搜索与回退 | 复用宿主 web_search 的现有后端回退；两个引擎的公共指令明确优先使用获授权的可用搜索，原生失败后使用当轮提供的宿主工具 | 原生到宿主的回退是模型按指令执行，不是直接调用另一个引擎的搜索 RPC；不为检索额外启动另一个模型；Codex 宿主的原生联网限制保留 |
| 5. 进程复用 | OpenCode 纯文本进程改为最多 3 个缓存，按现有主体/会话状态目录、模型、凭据摘要隔离；闲置 120 秒回收，凭据变更重建，取消/失败退出缓存 | 携带当轮 MCP 或代理凭据的进程仍随回合关闭；Codex 已有控制进程池沿用 |

- 后端联合回归：271 通过、7 跳过。跳过项为缺少 trafilatura、仅在缺少 httpx 时执行的分支，以及 Windows 上不适用的 POSIX 权限测试。
- 前端相关测试：30 通过；生产构建通过。
- 全仓 TypeScript 检查未通过：错误集中在本次未修改的浏览器分类、国际化等文件；本次新增/修改的引擎相关文件未报告类型错误。
- OpenCode 官方免费模型 `big-pickle` 连续两次真实调用成功，确认复用同一个 client/进程。本次耗时 9,703 ms、1,360 ms；单次样本不能作为普遍性能承诺。
- 宿主 DDG 真实搜索返回 5 条结果，统一字段校验通过，耗时 8,000 ms。
- Codex Responses 代理测试包含真实本地 App Server 对受控测试上游的调用，不代表已验证任意第三方云服务。
