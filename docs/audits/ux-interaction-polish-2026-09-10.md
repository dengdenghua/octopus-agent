# Echo 交互补齐记录 · 2026-09-10

本轮完成代码修复和自动化验证；不代表已完成官方 Codex 的全部 UX 对标。

## 已修复

1. **草稿退出保存**：原来 300 ms 防抖在组件卸载时被取消，最后输入的文字可能未保存。现在在页面隐藏和卸载时保存最新已提交状态；发送后空草稿同样落盘，避免重新打开时恢复已发送内容。范围为文字草稿，不包含二进制附件的跨刷新恢复。
2. **中文输入法**：输入法候选确认、方向键、退格优先交给输入法；同时识别 `isComposing` 和兼容事件 `keyCode=229`，避免命令菜单、引用控件或发送逻辑误截获。
3. **右栏拖动取消**：Esc 或窗口失焦取消本次拖动，保留原宽度，不触发全屏展开，并恢复先前鼠标与文字选择样式。仅主鼠标键启动拖动。
