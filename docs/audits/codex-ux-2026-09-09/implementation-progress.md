# 工作台联动实施记录 · 2026-09-09

## 已实现

- ChatPageLayout 增加 split/content-full 布局状态；工作台按钮切换全宽和分栏。
- 向左拖拽分隔线，候选工作台宽度达到容器宽度减 160px 时，松手进入全宽。拖回阈值外再松手则继续普通缩放。进入全宽不会覆盖此前分栏宽度。
- 全宽时隐藏消息栏，原 inputArea 保持挂载并显示为居中悬浮输入区；工作台底部按输入区实际高度预留空间。
- 桌面 inline/drawer/full 共用同一工作台节点，切换不因布局分支重新挂载预览。
- 移动端仍用原有底部抽屉，返回桌面恢复全宽意图；关闭工作台或切换任务时重置全宽。
- 提供中、英、日、韩文按钮文案。拖拽监听卸载时取消动画帧并恢复光标。

## 验证证据

- TypeScript --noEmit 通过。
- chat-page-layout、agent-workbench-panel、chat-input-box：161 项通过，2 项既有跳过。
- 布局测试覆盖：输入和预览节点身份不变、草稿保留、原宽度恢复、拖拽吸附与撤回、移动端回退。
- localhost:3310 实际浏览器 1280×720：打开工作台 → 全宽 → 预览加载 → 输入测试草稿 → 恢复分栏，草稿和预览保持；随后清空测试草稿并回到全宽。
- 实际预览为浏览器自动化图像表面，底部日志位于输入区之上。没有执行发送消息或网页业务操作。
