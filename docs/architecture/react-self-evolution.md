# ReAct 与自进化

ReAct 执行循环交替进行分析、工具调用和结果观察，直到产生结果、需要用户介入，或达到运行边界。

任务记录也可以作为自进化的输入：提取失败规律、整理可复用记忆、比较执行策略。一次任务完成不等于新的策略已经发布；评估、保护设置和发布状态需要分别查看。

在当前界面中：

- 在对话的运行设置中查看执行引擎，在消息标记中核对实际执行引擎。
- 在“自进化”中查看治理、候选与运行状态。
- 在“规则”中查看规则命中和覆盖情况。
- 在“运行诊断”中查看服务可用性。没有读取到状态时，不能据此认定系统正常。
