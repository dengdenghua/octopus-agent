## 🎨 设计原则

### 1. 渐进披露（Progressive Disclosure）
不一次性展示所有信息，而是分层提供：
- **默认**：关键信息（标题、进度、状态）
- **Hover**：详细预览（统计、描述）
- **点击**：完整详情（所有数据）

### 2. 信息密度可调
用户根据场景选择密度：
- **正常模式**：清晰易读（适合实时监控）
- **紧凑模式**：高密度（适合回顾总结）

### 3. 性能优先
确保流畅体验：
- **memo 优化**：减少渲染
- **智能折叠**：限制 DOM
- **延迟加载**：Hover 时才创建预览

### 4. 一致性
复用现有设计语言：
- **颜色**：success/destructive/warning
- **图标**：lucide-react 统一风格
- **组件**：shadcn/ui 标准组件
- **动画**：tailwind 过渡效果
