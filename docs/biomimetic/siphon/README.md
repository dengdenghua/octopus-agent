# 💨 Siphon · 漏斗

**生物原型**：章鱼的漏斗是多功能器官 —— 喷射推进、呼吸换气、排废、墨囊出口全靠它。

## 职责
对外 I/O 管道：
- **SSE / WebSocket / HTTP** 流式响应
- **OpenAI-Compat Gateway**（fork）—— 任何 OpenAI SDK 可把本系统当后端
- **压缩与背压** —— 像漏斗的肌肉环控制喷射力度

## 子目录
```
siphon/
└── openai_gateway/    [fork]  OpenAI API 兼容层
```

## 三种喷射模式
1. **推进模式**：流式返回 token 给客户端
2. **呼吸模式**：双向流（输入 + 输出）
3. **排废模式**：墨囊触发时，把熔断信号喷出去通知上游

## 进化关联
- **⑥ 成本治理**：Ink 熔断后由 Siphon 发出"降级/拒绝"响应
- 兼容层降低用户迁移成本，是生态护城河之一
