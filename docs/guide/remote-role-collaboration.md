# 按角色协作

远程群成员是接收方的角色身份，例如 Zero。委派方发送任务和获准共享的上下文；接收方用该角色自身的配置及本机调度策略选择执行引擎和模型。不会把委派方的模型、引擎或本地会话设置传入接收方运行配置。

在「远程角色」面板展开「邀请我的角色参与协作」，选择本机角色，生成并复制角色连接地址。同事通过已有网络或隧道连接，在「添加远程角色」注册地址及所需认证，然后加入群聊，使用 @ 点名委派。

每个角色拥有独立的持久地址和任务存储。切换引擎不改变该地址；不同角色不会共用身份。删除本机角色后，原地址的任务失败，不会悄悄改交 general。公开入口沿用 Echo 已配置的认证，生成地址不会自动开放公网或签发访问凭证。

目前接收任务保留原有隔离、只读对话权限，通过统一宿主执行上下文交给本机角色调度。模型额度共享是单独入口；Codex、OpenCode、WorkBuddy 直连仍可作为专用执行器使用。
