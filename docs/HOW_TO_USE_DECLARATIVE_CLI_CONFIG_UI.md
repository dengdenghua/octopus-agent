# 声明式本地 CLI 伙伴 - 前端 UI 使用指南

## 🎨 前端用户如何使用

作为前端用户，你**无需修改任何代码**，只需在 UI 中操作即可使用本地 CLI 伙伴。

---

## 📱 使用流程

### 第一步：检测本地 CLI 工具

1. **打开设置**
   - 点击右上角的 **设置图标** ⚙️
   - 或使用快捷键（Mac: `Cmd + ,` / Windows: `Ctrl + ,`）

2. **进入"本地伙伴"设置**
   - 左侧菜单找到 **"本地伙伴"** 或 **"Local Partners"**
   - 点击进入

3. **检测已安装的 CLI**
   - 点击 **"扫描本地 CLI"** 或 **"Detect Local CLIs"** 按钮
   - 系统会自动检测：
     - ✅ OpenCode CLI
     - ✅ Claude Code CLI
     - ✅ Codex CLI
     - ✅ CodeBuddy CLI
     - ✅ Trae CLI
     - ✅ Qoder CLI
     - ✅ Kimi CLI

4. **注册检测到的 CLI**
   - 勾选你想使用的 CLI
   - 点击 **"注册"** 或 **"Register"**
   - 等待注册完成（几秒钟）

---

### 第二步：使用本地 CLI 伙伴

#### 方法 1：在聊天中 @提及

1. **开始新对话**
   - 点击 **"新建对话"** 或 `+` 按钮

2. **@提及 CLI 伙伴**
   ```
   @OpenCode 帮我分析这个 bug
   ```
   
   或
   
   ```
   @Claude Code 实现一个登录功能
   ```

3. **选择模型（可选）**
   - 如果 CLI 支持模型选择（OpenCode、Claude Code、CodeBuddy）
   - 在 **"伙伴模型"** 下拉菜单中选择模型
   - 例如：`deepseek/flash`、`claude-opus-4`

4. **发送任务**
   - 输入任务描述
   - 点击发送 📤
   - CLI 伙伴会直接执行，无需经过 Octopus 的 LLM

#### 方法 2：在团队面板中指派

1. **打开团队面板**
   - 左侧点击 **"团队"** 或 **"Team"** 图标 👥

2. **查看可用成员**
   - 你会看到所有注册的本地 CLI 伙伴
   - 每个伙伴旁边有一个头像和状态指示器

3. **直接指派任务**
   - 点击 CLI 伙伴的名称
   - 在弹出的对话框中输入任务
   - 点击 **"派发"** 或 **"Assign"**

#### 方法 3：在实时协作中使用

1. **创建团队会话**
   - 点击 **"新建团队会话"**
   - 选择要加入的成员（可以包括本地 CLI 伙伴）

2. **在讨论中提及**
   ```
   @OpenCode 你来处理这个前端优化任务
   @Claude Code 你负责写测试
   ```

3. **实时协作**
   - 多个 CLI 伙伴可以同时工作
   - 通过共享黑板（blackboard）协作

## 🎯 UI 中的关键功能

### 1. 伙伴模型选择器

当你选择了本地 CLI 伙伴后，会出现 **"伙伴模型"** 下拉菜单：

```
┌─────────────────────────────┐
│ 选择模型                     │
├─────────────────────────────┤
│ ● auto (CLI 默认)            │
│   deepseek/flash             │
│   deepseek/chat              │
│   anthropic/claude-sonnet-4  │
│   anthropic/claude-opus-4    │
│   openai/gpt-4               │
└─────────────────────────────┘
```

**说明**：
- **auto**：使用 CLI 自己配置的默认模型
- **其他选项**：覆盖 CLI 的默认模型（如果 CLI 支持）

**支持模型选择的 CLI**：
- ✅ OpenCode CLI（支持 `-m` 参数）
- ✅ Claude Code CLI（支持 `--model` 参数）
- ✅ CodeBuddy CLI（支持 `--model` 参数）
- ✅ Codex CLI（支持 `-m` 参数）
- ❌ Trae CLI（暂不支持模型参数）
- ❌ Qoder CLI（使用 CLI 默认模型）

---

### 2. 本地伙伴状态指示器

在团队面板中，每个本地 CLI 伙伴旁边有状态指示：

- 🟢 **绿色**：就绪，可以派发任务
- 🟡 **黄色**：正在执行任务
- 🔴 **红色**：不可用（CLI 未安装或未登录）
- ⚪ **灰色**：未注册

**点击状态指示器**可以查看详细诊断信息。

---

### 3. 本地伙伴诊断工具

如果 CLI 伙伴无法工作，可以使用诊断工具：

1. **进入"本地伙伴"设置**
2. **找到有问题的 CLI**
3. **点击"诊断"按钮** 🔍
4. **查看诊断报告**：
   ```
   ✅ CLI 已安装
   ✅ 可执行文件路径正确
   ❌ 未登录（需要在原生 CLI 中登录）
   💡 建议：在终端运行 `opencode login`
   ```

5. **按照建议修复**

## ❓ 常见 UI 问题

### Q1: 为什么我看不到本地 CLI 伙伴？

**A**: 可能原因：
1. CLI 未安装 → 在终端安装 CLI
2. 未注册 → 进入设置 → 本地伙伴 → 扫描并注册
3. 未检测到 → 点击"刷新"重新扫描

---

### Q2: 状态指示器是红色的怎么办？

**A**: 点击红色指示器查看诊断，常见原因：
- **未登录**：在终端运行 CLI 并登录
- **权限不足**：在原生 CLI 中信任当前项目
- **模型不可用**：换一个模型或在 CLI 中配置默认模型

---

### Q3: 伙伴模型选择器没有出现？

**A**: 说明当前 CLI 不支持模型参数。
- 支持的：OpenCode、Claude Code、CodeBuddy、Codex
- 不支持的：Trae、Qoder

---

### Q4: 任务一直卡在"执行中"？

**A**: 可能原因：
1. **CLI 在等待交互确认** → 这正是我们修复的问题！
   - OpenCode 需要 `--auto` 标志
   - CodeBuddy 需要 `-y` 标志
   - 现在已经在配置中添加了
2. **任务太复杂** → 等待更长时间或拆分任务
3. **CLI 崩溃** → 查看诊断日志

---

### Q5: 可以同时使用多个 CLI 吗？

**A**: 可以！在团队会话中：
1. 创建团队会话
2. 添加多个 CLI 伙伴
3. 用 `@` 分别指派任务
4. 它们会同时工作

## 📱 移动端支持

目前，本地 CLI 伙伴**仅支持桌面端**，因为：
- CLI 需要在本机安装
- 需要访问本地文件系统

**移动端**可以：
- ✅ 查看 CLI 伙伴的执行结果
- ✅ 派发任务给 CLI 伙伴（如果桌面端在运行）
- ❌ 注册新的 CLI
- ❌ 修改 CLI 配置
