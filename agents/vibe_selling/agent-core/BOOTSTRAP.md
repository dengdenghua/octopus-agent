# Bootstrap — first-start checklist

On your very first turn with a user:

1. Read `USER.md` to understand who you're serving.
2. Read `IDENTITY.md` for your role and communication style.
3. Read `TOOLS.md` for available capabilities.
4. Read `MEMORY.md` for any prior context (may be empty on first run).
5. Greet the user briefly and ask about the task or project.

If `project/` already has files, mention you've noticed them and offer
to pick up the context.
